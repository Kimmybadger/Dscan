# 문서 스캐너 (Doc Scanner)

아이폰 사파리에서 카메라로 문서를 찍고, 자동/수동으로 테두리를 맞춘 뒤,
스캔한 느낌으로 보정해 하나의 PDF로 저장하는 순수 웹앱입니다.
서버가 필요 없고, 홈 화면에 앱처럼 추가해서 쓸 수 있습니다 (PWA).

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다 (예: `doc-scanner`).
2. 이 폴더 안의 파일 5개를 모두 저장소 루트에 업로드합니다.
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 저장소 **Settings → Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 설정하고 저장합니다.
5. 1~2분 뒤 `https://[깃허브아이디].github.io/doc-scanner/` 주소로 접속하면 앱이 열립니다.

> GitHub Pages는 자동으로 HTTPS를 제공합니다. 카메라(`getUserMedia`)는
> HTTPS 환경에서만 동작하므로 별도 설정 없이 바로 사용할 수 있습니다.

## 아이폰 홈 화면에 앱으로 추가하기

1. 사파리로 위 주소에 접속합니다.
2. 공유 버튼(⬆️) → **홈 화면에 추가**를 누릅니다.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 전체 화면으로 열립니다.
4. 한 번 방문한 뒤에는 서비스 워커가 파일을 캐시해서, 다음부터는 인터넷이 불안정해도
   앱 자체는 열립니다 (다만 최초 1회는 온라인 상태에서 접속해야 합니다).

## 사용법

1. 앱을 열면 카메라 화면이 바로 뜹니다. 문서를 화면 안에 맞추고 셔터를 누릅니다.
2. 사진이 찍히면 자동으로 문서 테두리를 감지해서 초록색 사각형으로 표시합니다.
   자동 인식이 부정확하면 모서리 점을 손가락으로 직접 옮겨서 맞출 수 있습니다.
3. 상단에서 **흑백 스캔 / 그레이스케일 / 컬러** 중 보정 방식을 고릅니다.
4. **이 페이지 저장**을 누르면 하단 필름스트립에 페이지가 추가되고, 다시 카메라로 돌아갑니다.
5. 여러 장을 계속 찍은 뒤 **완료 → PDF 저장**을 누르면 모든 페이지가 한 개의 PDF로 합쳐져
   다운로드(공유 시트)됩니다.
6. 필름스트립의 페이지 썸네일 오른쪽 위 `×`를 누르면 해당 페이지를 삭제할 수 있습니다.

## 기술 구성

- 순수 HTML/CSS/JS, 빌드 과정 없음
- 카메라: `getUserMedia` (실시간 뷰파인더)
- 테두리 자동 인식 & 원근 보정: [OpenCV.js](https://docs.opencv.org/) (CDN 로드)
- PDF 생성: [jsPDF](https://github.com/parallax/jsPDF) (CDN 로드)
- 오프라인 앱 셸 캐싱: Service Worker (`sw.js`)
- 홈 화면 설치: Web App Manifest (`manifest.json`)

## 참고

- 최초 로딩 시 OpenCV.js(약 8MB)를 내려받기 때문에 처음 켤 때만 약간 시간이 걸릴 수 있습니다.
  이후에는 서비스 워커 캐시 덕분에 빨라집니다.
- 자동 테두리 인식이 항상 완벽하지는 않습니다. 배경과 문서의 명암 차이가 클수록 잘 잡힙니다.
